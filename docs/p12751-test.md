## First trial — OptEarly + EarlyLoad
Default new boot preference is OptEarly (optimized driver plus early
layout nil). Expect latch=3 or 7; bit 2 means retained data. Host checks
variant before arming. Actual opener path should name
/redwood/lib/libvulkan_panfrost_opt.dylib;
check ABI reason and early_nil/use counters rather than assume success.
Fresh cooled boot, screen OFF, USB connected, close PuTTY. Arm before
uptime 225s. No touch/swipe during the measurement. Existing hard stops
BIG76/LITTLE70/GPU72 and absolute deadline 720s unchanged. EarlyLoad
uses NOW with no coordination; preemptive load envelope begins after arm.

```powershell
powershell -ExecutionPolicy Bypass -File .\s9-p1274-serial.ps1 -Profile LOG2 -Experiment EarlyLoad -BootVariant OptEarly -AllowIntervention -Port COM125 -RunDir .\logs\P12751-OptEarly-A0 -Execute
```

COM125 is an example; substitute the actual port. If latch or actual
driver is wrong, stop and report rather than relabel the trial. If
thermal stop occurs, cool first. Do not force repeated hot captures.
