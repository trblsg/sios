## Next after reviewing A0: independent idle tests, no new flash

A0 uses P127_BASE (policy=1), which implies the existing P126 low four driver bits (driver=15); it is a matched policy baseline, not an entirely stock baseline. In firmware a779995 this inherited mask also prevents the new 13-domain P12752 GET path (`!r.driver`). BusTrace still reads the older eight cached P1273 domains with timestamp/errno/valid flags; do not infer a zero clock from invalid or missing readbacks. Full 13-domain collection requires a future kernel fix, not this host hotfix.

Use a fresh cool boot or matched quiet baseline for each command; never
stack policy leases. Host A/B/A is one module, not a suite. If evidence
is incomplete, a policy is refused, or wake/foreground fails, stop.
PSR uses governor threshold 100ms, not a legacy fb_psr timer. Frame
counter is not measured DSI/DRAM traffic. Verify wake and normal screen
updates manually after restoration before progressing.

```powershell
# All 13 ACPM GETs, separate diagnostic (not a pure power baseline)
powershell -ExecutionPolicy Bypass -File .\s9-p125-timer-serial.ps1 -Scenario BusTrace -P12752Idle -Port COM125 -Execute

powershell -ExecutionPolicy Bypass -File .\s9-p125-timer-serial.ps1 -Scenario EnergyTrials -P12752Idle -EnergyModules PSR -EnergySeconds 30 -Port COM125 -Execute

powershell -ExecutionPolicy Bypass -File .\s9-p125-timer-serial.ps1 -Scenario EnergyTrials -P12752Idle -EnergyModules LITTLE949 -EnergySeconds 30 -Port COM125 -Execute

powershell -ExecutionPolicy Bypass -File .\s9-p125-timer-serial.ps1 -Scenario EnergyTrials -P12752Idle -EnergyModules BT -EnergySeconds 30 -Port COM125 -Execute
```

## Battery-only quiet window (after connected A0 review)

```powershell
powershell -ExecutionPolicy Bypass -File .\s9-p125-timer-serial.ps1 -Scenario Idle52Offline -P12752Idle -EnergySeconds 60 -AllowOfflineTrial -Port COM125 -Execute
```

Unplug/reconnect only at host prompts; do not wake screen, keep the
same boot. After unplug, COM may still enumerate briefly while Read()
already reports closed; the host now confirms disappearance, holds the
full 60s without reads, and prompts RECONNECT USB NOW. Reopen retries are
bounded to the requested COM; a new read-only fence and P125 phase/anchor
check must pass before further policy writes. If Windows assigns a different
COM on replug, use -ReconnectPort COMxxx on a fresh run with the known
port; never guess another serial device. If the previous run aborted,
use a fresh cooled boot before rearming (old leases may still be active).
Kernel stops autonomously for thermal/load/lease conditions.
If uncomfortable heat or malfunction, stop; do not continue a hot run.
Send partial logs too. Power.json uses signed FG samples, external=0,
negative current, contiguous sequence and >=80% temporal coverage.
A verified=false or missing file is no battery-power conclusion.
Connected net battery power is not device consumption.
